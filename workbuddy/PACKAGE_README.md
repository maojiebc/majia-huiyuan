# 会员增长数据顾问·马甲实战版

这是 WorkBuddy 单专家安装包。它帮助你说清会员指标怎么算、发现数据缺口，并把复购、留存和召回问题拆成可以核对的数据与行动。

- [专家说明](agents/majia-huiyuan.md)
- [知识入口](skills/majia-huiyuan/SKILL.md)
- [三个实战问题](skills/majia-huiyuan/公式库/实战问题入口.md)
- [公式库目录](skills/majia-huiyuan/公式库/README.md)
- [完整项目](https://github.com/maojiebc/majia-huiyuan)

可以先问：“两张报表的复购率不一样，帮我核对分母、时间窗和去重规则。”

包内保留字段定义、公式、示例 SQL 与看板文档；模拟数据样本、历史平台文件和方法论插图在 GitHub 完整项目中。所有样板数值均为模拟，不能当作真实业绩或行业基准。示例 SQL 需结合自己的数据验证。

版本号见 `.codebuddy-plugin/plugin.json`。包能解析、平台审核通过、安装后实际可用，需要分别验证。
