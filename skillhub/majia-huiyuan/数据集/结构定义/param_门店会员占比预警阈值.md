# param_门店会员占比预警阈值

> v1.4.1 将原先误命名的 `param_会员生命周期阈值` 更正为本表。它只控制门店会员订单占比的月度下降预警，与会员生命周期天数无关。

## 粒度与主键

- 粒度：一行 = 一个门店类型
- 主键：`门店类型`

## 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 门店类型 | STRING | 与门店主档的门店类型对齐 |
| 会员占比月降幅预警 | DOUBLE | 本月较上月下降达到该百分点时预警 |
| 定标方法 | STRING | 同店型历史分布与业务复核方式 |

## 质量规则

- 门店类型不得重复或为空
- 阈值须在 `[0, 1]` 内
- 需要预警的每个门店类型必须有且只有一行
- 本仓库阈值均为模拟示例，不是行业基准
