# param_会员生命周期阈值

> v1.4.1 逻辑参数表。用于统一定义活跃、沉睡、流失的观察窗口；生产环境应由业务线负责人和数据负责人共同定标并保留版本。

## 粒度与主键

- 粒度：一行 = 一个业务线 × 一个会员类型 × 一个生效版本
- 建议主键：`业务线, 会员类型, 生效日期`
- 时间关联：事实快照日期须落在 `[生效日期, 失效日期]`；`失效日期` 为空代表长期有效

## 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 业务线 | STRING | 品牌或业务线；样板数据使用“全品牌” |
| 会员类型 | STRING | 与 `dim_会员主档.会员等级` 对齐 |
| 活跃天数上限 | INT | 距末单天数不超过该值时视为活跃 |
| 沉睡天数上限 | INT | 超过活跃上限且不超过该值时视为沉睡 |
| 流失天数上限 | INT | 超过沉睡上限且不超过该值时视为高风险流失；再往后为长期流失 |
| 生效日期 | DATE | 参数版本生效日 |
| 失效日期 | DATE | 参数版本失效日，可空 |
| 定标方法 | STRING | 参数来源和复核方法，便于审计 |

## 质量规则

- `0 < 活跃天数上限 < 沉睡天数上限 < 流失天数上限`
- 同一业务线、会员类型的生效区间不得重叠
- 每个有效会员类型在 `as_of_date` 必须且只能命中一条参数
- 本仓库数值均为模拟示例，不是行业基准
