# 客单价

一笔有效订单平均收到多少钱，先去掉一单多行。

怎么算：金额合计除去重有效订单数。跨日合并按金额与订单重新相除；税口径、退款口径必须保持一致。

模拟：甲的一单含两件商品共30元，乙40元，丙50元。客单120/3=40元；不能按四件商品把客单算成30元。
