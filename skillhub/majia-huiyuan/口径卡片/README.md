# 口径卡片

先选统计对象、分母、时间窗和去重键，再取SQL。卡片说明平台无关的定义；majia-guanyuan的“看板口径档案”记录某个观远看板实际取数的证据，二者分工不同。

以下数值例子全部模拟，不是经营效果或行业阈值。公式库的通用字段需映射到实际表；当前仓库缺少的支付分摊、异常标记、实验结果等证据明确保留缺口。

| 卡片 | 回答什么 |
|---|---|
| [复购率：跨天与非跨天](01-repurchase.md) | 同日第二笔能否算复购，必须在统计前选定。 |
| [同期群留存率](02-cohort-retention.md) | 未走完的月份留空，不能拿暂时没有订单当流失。 |
| [会员生命周期阶段](03-lifecycle.md) | 阶段由注册、订单与有效参数共同决定，不是一刀切天数。 |
| [RFM分层：两套并存](04-rfm.md) | 八类快速分组与九类精细分层有不同阈值体系。 |
| [有效新增：扫码、加好友、注册和首购分开](05-valid-new-members.md) | 四个事件各报各的有效人数，不能相加当总拉新。 |
| [会员销售占比](06-member-sales-share.md) | 会员金额占比与会员订单占比回答不同问题。 |
| [客单价](07-average-order-value.md) | 一笔有效订单平均收到多少钱，先去掉一单多行。 |
| [券核销率：按券与按人](08-coupon-redemption.md) | 先固定发券批次和观察日，再选券实例或人数。 |
| [核销GMV成本比](09-redemption-gmv-cost.md) | 这个比值是关联订单金额除已记录优惠成本。 |
| [触达后关联GMV与关联下单率](10-touch-associated-gmv.md) | 窗口内的关联说明时序，不说明因果增量。 |
| [增量GMV与增量ROI](11-incremental-roi.md) | 没有合格对照时保留NULL，不把关联金额减成本当增量。 |
| [渠道迁移](12-channel-migration.md) | 近30天与之前60天是互不重叠的两段订单窗口。 |
| [任务漏斗三率：触达、转化与价值兑现](13-task-funnel.md) | 执行、转化与预估兑现分开看，分别回答三个问题。 |
| [储值消费占比](14-stored-value-share.md) | 只数消费时实际用掉的储值部分，充值不是门店消费收入。 |
| [加盟回本月数](15-franchise-payback.md) | 按投资起点与历史店面贡献利润测算，不是回本承诺。 |
| [门店利润健康等级](16-profit-health.md) | 等级按店面贡献利润判断，持续亏损另看连续月份。 |

任务漏斗按作者确认的三率记录；储值卡只说明定义，不假装当前字段已能计算组合支付。核销按人与按券、八类与九类RFM分别命名。
