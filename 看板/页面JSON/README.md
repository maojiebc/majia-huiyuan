# 页面 JSON 可信边界

本目录保留 2026-06-24 观远 BI workshop 的 **v1.4.0 页面布局历史快照**，用于审计原布局、卡片配置与资源依赖。

这些 JSON 没有同步改造成 v1.4.1 可直接导入包，其中仍包含 `私域贡献销售`、`券ROI` 等已废弃字段名以及不可移植的 workshop 资源 ID。请勿把它们作为当前 schema 或业务口径来源。

v1.4.1 的当前依据是：

- `看板/页面文档/`：校正后的卡片字段清单；
- `ETL/逻辑SQL/` 与 `ETL/公共口径/`：校正后的数据逻辑；
- `数据集/结构定义/` 顶部 v1.4.1 覆盖与 `数据集/数据样本/` 表头：当前输出 schema。

生产落地时应在目标平台重建字段映射和卡片配置，并重新生成资源 ID。
